# ТЗ 7. Карта покрытия района Бишкека

Осенний хакатон INAI 2026. По замерам сигнала строим карту покрытия района,
находим слабые зоны и выбираем две площадки для новых базовых станций.

## Запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python main.py
```

Результат появится в папке `output/`:

- `output/result.json` — ответ в формате задания;
- `output/coverage_map.html` — интерактивная карта (открыть в браузере).

### Запуск на других данных (скрытый набор жюри)

```bash
python main.py --data path/to/folder --out path/to/output
```

В папке ожидаются `measurements.csv`, `towers.csv`, `candidates.csv`, `bounds.json`.
Любой файл можно указать отдельно, остальные берутся из `--data` (по умолчанию `data/`):

```bash
python main.py --measurements hidden/measurements.csv
```

Другие флаги: `--no-map` (только result.json), `-v` (подробный лог), `--help`.
Код возврата `2` и понятное сообщение — если файла нет или в нём нет нужных колонок.

### Тесты

```bash
python -m pytest
```

68 тестов: геометрия, каждый вид мусора, сетка и пороги цветов, выбор площадок,
и сквозной тест, что на открытых данных результат совпадает с `data/expected.json`.

## Что сделано (обязательная часть)

1. **Очистка данных** (`coverage/cleaning.py`). Строка отбрасывается, если она пустая,
   с неверным числом колонок, с пропущенным значением, с нечисловым / `NaN` / `Infinity`
   числом, с неверным временем (не ISO 8601, например `2026-13-01`), с RSRP вне
   −140…−44 дБм, с координатами вне прямоугольника `bounds.json` (границы включены),
   или это дубль. Дубли ищутся по четырём нормализованным полям: числа сравниваются
   как числа (`-112.9` = `-112.90`), время — как момент времени. Число отброшенных строк
   выводится в консоль с разбивкой по причинам.
2. **Сетка 200×200 м** (`coverage/geo.py`, `coverage/grid.py`) в локальной
   равнопромежуточной проекции из уточнений:
   `x = R·cos(lat0)·rad(lon−lon0)`, `y = R·rad(lat−lat0)`, клетка `(floor(x/200), floor(y/200))`,
   `cell_id = X{ix:03d}_Y{iy:03d}`. Медиана RSRP по клетке, клетки с < 5 замерами не учитываются.
3. **Цвета**: зелёный ≥ −90 дБм, жёлтый −105…−90, красный < −105 (слабая зона).
4. **Топ-3 худших клетки** — по медиане, при равенстве по `cell_id`.
5. **Выбор двух площадок** (`coverage/placement.py`). Площадка допустима, если до
   каждой существующей БС ≥ 500 м. Площадка покрывает красную клетку, если до её центра
   ≤ 1000 м (гаверсинус, R = 6 371 000 м). Перебираются все пары допустимых площадок,
   максимизируется размер объединения покрытых клеток (без двойного учёта).
   При равенстве — лексикографически меньшая пара ID.

**Карта** (`coverage/mapviz.py`, folium): цветные клетки с подсказками (медиана, число
замеров), топ-3 худших, существующие БС, все кандидаты (недопустимые отмечены),
выбранная пара с кругами 1 км, легенда со сводкой. Слои включаются и выключаются.

## Структура

```
main.py                 точка входа
coverage/
  cli.py                аргументы командной строки, запись результатов
  pipeline.py           весь расчёт: загрузка → очистка → сетка → площадки
  config.py             bounds.json
  cleaning.py           чтение и очистка measurements.csv
  geo.py                гаверсинус, локальная сетка
  grid.py               медианы по клеткам, цвета, худшие клетки
  sites.py              towers.csv, candidates.csv
  placement.py          допустимость площадок, покрытие, перебор пар
  report.py             result.json и текстовая сводка
  mapviz.py             HTML-карта
tests/                  pytest
data/                   открытые данные задания и expected.json
```

## Что не успели / в планах

- Бонус: сравнение жадного алгоритма с полным перебором.
- Бонус: сравнение покрытия днём и ночью.
- Бонус: тепловая карта.

Для просмотра карты нужен интернет (подложка OpenStreetMap и скрипты Leaflet грузятся из CDN).

Важно: OpenStreetMap не отдаёт тайлы странице, открытой двойным кликом (`file://`).
Карту нужно открывать по http: на GitHub Pages (деплой делает `.github/workflows/pages.yml`)
или локально:

```bash
python -m http.server 8000 --directory output
```

и открыть http://localhost:8000/coverage_map.html.
